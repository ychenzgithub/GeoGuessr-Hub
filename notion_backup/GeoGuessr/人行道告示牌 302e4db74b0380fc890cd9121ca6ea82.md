# 人行道告示牌

# 欧洲底部标线

- 常规： 欧洲大部分国家，蓝底白背景告示牌中的黑色小人下方伴有斑马线。
- 没有此类告示牌：英国、爱尔兰
- 一条横实线： 波兰
- 两根横虚线： 比利时(方脑袋)、奥地利、希腊、黑山
- 三条竖线：俄罗斯、乌克兰、爱沙尼亚（人瘦一些）、立陶宛
- 四条竖线：
    - 瑞典：有脖子
    - 挪威：没有明显的脖子
    - 冰岛：蓝底黄三角
    - 保加利亚：带帽子
- 五条竖线
    - 其他大部分欧洲国家
    - 竖线碰到三角框：丹麦
    - 竖线很靠中间（有两条几乎被脚遮住）：斯洛伐克
    - 有皮带：德国、克罗地亚、匈牙利、葡萄牙
- 七条竖线：瑞士
- 八条竖线：西班牙

# 黄色菱形阵营

在这些地区，人行道告示牌通常采用**黄色背景、菱形形状**，黑色图案被包围在黄色框内 。

- **北美洲（美国、加拿大）**： 典型的黄色菱形告示牌 。美国有时会在下方配有写着“PED XING”的辅助说明牌。
- **拉美地区（墨西哥、危地马拉、巴西、哥伦比亚、阿根廷、智利、秘鲁）**： 同样广泛使用黄色菱形警告标志 。
- **大洋洲（澳大利亚、新西兰）**： 标志性的黄色菱形，图案通常是一个正在行走的人影 。
- **亚洲（日本、大部分东南亚国家如泰国、马来西亚）**： 日本和东南亚地区也普遍采用黄色菱形作为行人警告标志 。
- **欧洲特例 - 爱尔兰**： 它是欧洲极少数不使用蓝底告示牌的国家，而是使用**黄色菱形**，资料中形象地描述为“被困在黄色菱形里的行人” 。
