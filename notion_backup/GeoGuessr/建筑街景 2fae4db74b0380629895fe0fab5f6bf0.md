# 建筑街景

- 安道尔：砖石墙
- 马耳他：黄色沙石墙
- 保加利亚：不平的瓦片
- 阿尔巴尼亚：屋顶白色圆筒状大水箱
- 尼日利亚：屋顶经常为五脊歇山形
- 卢旺达：砖混建筑上常有花纹通风口；街面很干净；经常有栏杆或高墙；摩托车手需带红色背心头盔
- 菲律宾：三轮车,混凝土道路
- 泰国：经常有类似小庙宇的神龛
- 不丹：路边混凝土方块护墩
- 厄瓜多尔：城区可能有六边形地砖
- 玻利维亚：城区可能有鹅卵石路；多MAS, EVO等政治性涂鸦；蓝色TIgo 广告
- 巴西：透明卫星天线，深蓝色水箱
- 墨西哥：大黑色水箱，墙外圆形电表
- 秘鲁：街道上多三轮车; 有时有编织芦苇席做围栏
- 乌拉圭：有时有Chivito（乌拉圭国家美食）标志
- 土耳其：哑铃形地砖贴铺
- 百慕大：白色屋顶
- 瑞士：百叶窗数量多
- 智利：有像亭子一样的公交车站
- 柬埔寨：有高脚屋子
- 孟加拉：竹编木栅栏，透明塑料细网，细河沙

| **区域 / 国家** | **石墙特征与材质** | **伴生景观与快速区分 Meta** |
| --- | --- | --- |
| **爱沙尼亚诸岛**

*(萨雷马/穆胡岛)* | 灰白色石灰岩，长满青苔或地衣，高度齐腰，呈自然粗糙堆砌（*Kiviaed*）。 | **平坦地貌 + 低矮刺柏（Juniper）**、松树与白桦；波罗的海灰暗阴天或Gen 3/4夏景。 |
| **瑞典 (厄兰/哥特兰岛)** | 规整平整的石灰岩薄板堆砌（*Stengärdsgård*）。 | 极开阔的阿尔瓦（Alvar）草原地貌、风车、典型北欧红色木屋（Falun red）。 |
| **马耳他 / 戈佐岛** | 明显的**暖黄/金黄色石灰岩（Globigerina）**，规整方正，风化孔隙明显。 | **无树干旱**、仙人掌/刺山柑、左舵行车（左行标志）、黄色白牌或长条车牌。 |
| **尤卡坦半岛 (墨西哥)**

*(坎昆/梅里达周边)* | 粗糙带孔的灰白/黄色石灰岩石块，常作为庭院矮墙（*Albarrada*）。 | **热带干热灌木林（Selva baja）**、极度平坦、白水泥平顶房、烈日顶光。 |
| **爱尔兰 / 英国**

*(尤以爱尔兰西部为甚)* | 灰黑色花岗岩或页岩，缝隙透光（如康尼马拉/阿伦群岛的透光石墙）。 | **极绿草丘**、起伏地形、阴雨潮湿感、左行红尾灯、黄色菱形标牌（爱尔兰）。 |
| **克罗地亚 / 达尔马提亚** | 浅白灰岩在沿海梯田与山坡蜿蜒（*Suhozid*），纵横交错。 | **喀斯特山地**、橄榄树丛、地中海灌木、波光粼粼的亚得里亚海。 |
| **意大利 (普利亚/西西里)** | 浅色石灰岩，普利亚常见于橄榄园与圆顶石屋（*Trulli*）之间。 | **红土壤**、百岁粗壮橄榄树、南欧强烈阳光、前排短白牌。 |
| **秘鲁 / 玻利维亚高原** | 泥土与深色圆砾石混筑，或印加风格巨石基座。 | **极高海拔安第斯荒漠草甸（Puna）**、羊驼、土坯房（Adobe）、黑白横纹反光柱。 |
