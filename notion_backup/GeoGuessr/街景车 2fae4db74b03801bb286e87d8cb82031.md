# 街景车

[Google Car](https://geometas.com/metas/categories/google_car/)

# 镜头类型

- **第一代 (Gen 1)**：极低分辨率，全屏模糊感。
    - *覆盖：日、法、美、加、澳、新、墨西哥。*实战中基本碰不到。
- **第二代 (Gen 2)**：画面底部和天空有巨大的“圆形模糊面”，色彩偏紫色。
    - *覆盖：西欧（除东欧）、北美、巴西、南非、俄罗斯。*
- **糟糕画质 (Shitcam)**：画面不仅模糊，且常伴随大面积圆圈遮挡。
    - **常见国家**：[**印度**](https://www.notion.so/yangchenuci/GeoGuessr-2fae4db74b0380f9ad53d3487bcc97f7)、[**柬埔寨**](https://www.notion.so/yangchenuci/GeoGuessr-2fae4db74b0380f9ad53d3487bcc97f7)、[**黎巴嫩**](https://www.notion.so/yangchenuci/GeoGuessr-2fae4db74b0380f9ad53d3487bcc97f7)、[**尼日利亚**](https://www.notion.so/yangchenuci/GeoGuessr-2fae4db74b0380f9ad53d3487bcc97f7)、[**厄瓜多尔**](https://www.notion.so/yangchenuci/GeoGuessr-2fae4db74b0380f9ad53d3487bcc97f7)。
- **第三代 (Gen 3)**：画质清晰但色彩饱和度较低，底部有车形状模糊。通常可见天线（或天线底座）。
- **第四代 (Gen 4)**：极高清，色彩鲜艳。*如果画质极好但看不见天线，优先考虑 Gen 4 覆盖区。*
- **Small cam**：跟四代机类似，极高清，色彩鲜艳，底下有很大非圆形模糊
    - 覆盖地区有
        - 南美（巴西，秘鲁），
        - 非洲（南非），
        - 亚洲（印度，土耳其），
        - 北美（美国，加拿大，波多黎各），
        - 欧洲（北欧，西欧，南欧有，自德国以东都没有）。
- **低视角相机 (Lowcam)**：视角明显贴近地面，车底模糊范围极大（仿佛蹲着看路），2-4代机都可能有。
    - **三剑客**：[**日本**](https://www.notion.so/yangchenuci/GeoGuessr-2fae4db74b0380f9ad53d3487bcc97f7)、[**瑞士**](https://www.notion.so/yangchenuci/GeoGuessr-2fae4db74b0380f9ad53d3487bcc97f7)、[**斯里兰卡**](https://www.notion.so/yangchenuci/GeoGuessr-2fae4db74b0380f9ad53d3487bcc97f7)。

# 运行方向

- 三代车：看见后面，
- 四代车（本田）：多为白色，看见前面，车后有时有刹车灯；分布于美洲，亚洲，大洋洲
- 四代车（欧宝）：多为蓝色（也有其它颜色），看见后面（屁股有凹进去的小坑）；分布于欧洲，南非

# 黑胶带

- [**加纳](https://www.notion.so/yangchenuci/GeoGuessr-2fae4db74b0380f9ad53d3487bcc97f7):** 右前方横杠上有明显黑胶带；车体前方Google地图标志经常可见。
- 留尼旺：右后方横杠上有黑胶带
- 多米尼加: 横杆中间和边上黑色保护垫。

# 金属横杠

- [**危地马拉](https://www.notion.so/yangchenuci/GeoGuessr-2fae4db74b0380f9ad53d3487bcc97f7):** 非常干净的银色金属横杆，黑色后视镜可见
- 吉尔吉斯斯坦: 与危地马拉类似，非常干净的银色金属横杆，黑色后视镜可见（左边后视镜里道路斜线接触上面-北部；接触左边或左上角-南部，靠近乌兹别克斯坦突出边境处）
- 法罗群岛: 偶尔见，与危地马拉类似
- 库拉索：与危地马拉类似，黑色，左前行李架有白贴纸
- 孟加拉国：偶尔有些车与危地马拉类似，红色后视镜
- [**塞内加尔](https://www.notion.so/yangchenuci/GeoGuessr-2fae4db74b0380f9ad53d3487bcc97f7)：**偶尔有些车与危地马拉类似，有时可见右后视镜

# **皮卡**

- [哈萨克斯坦](https://www.notion.so/yangchenuci/GeoGuessr-2fae4db74b0380f9ad53d3487bcc97f7)：白色皮卡，中间带螺纹黑色天线，经常只露出车头前端，车身经常被模糊掉
- [卡塔尔](https://www.notion.so/yangchenuci/GeoGuessr-2fae4db74b0380f9ad53d3487bcc97f7)：白色皮卡，经常被完全模糊，车前左侧有细长天线
- 阿曼：白色皮卡，有天线底座，有时没有天线，经常被完全模糊
- 厄瓜多尔：四代白色皮卡，黑色车斗，没有天线，有时可见红色刹车灯，经常被完全模糊
- 巴拿马：白色皮卡，中间黑色天线，整个车头和部分车身可见，车身上两根金属横杠，有竖立的金属框架，车身经常被模糊掉
- 哥斯达黎加：白色皮卡，中间黑色天线，整个车头和部分车身可见，车身上两根金属横杠
- 纳米比亚：白色皮卡，天线粗且明显偏向左边
- [卢旺达](https://www.notion.so/yangchenuci/GeoGuessr-2fae4db74b0380f9ad53d3487bcc97f7)：白/黑/棕色皮卡，经常带红色刹车灯
- 土耳其：偶尔有灰黑色皮卡
- 美属萨摩亚：黑色皮卡，车斗生锈，露出很多，右车头可能也有细天线
- 百慕大：黑色方形皮卡
- 蒙古：有时有蓝色花纹皮卡，带涉水喉
- [乌干达](https://www.notion.so/yangchenuci/GeoGuessr-2fae4db74b0380f9ad53d3487bcc97f7) ：白色方形皮卡
- 塞内加尔：有时有有银色皮卡，顶部有天线，稍偏左边，车斗有两根横杠
- [肯尼亚](https://www.notion.so/yangchenuci/GeoGuessr-2fae4db74b0380f9ad53d3487bcc97f7)：各式各样皮卡，右前方露出黑色涉水喉

# **天线**

- 卡塔尔：左车头有向上的细长天线
- 波多黎各/关岛/北马里亚纳：三代车右车头有向上的细长天线; 尼日利亚有时候也有这种天线

# **护航**

- [**尼日利亚**](https://www.notion.so/yangchenuci/GeoGuessr-2fae4db74b0380f9ad53d3487bcc97f7)：常见警车护航（可见警灯）。
- [**突尼斯**](https://www.notion.so/yangchenuci/GeoGuessr-2fae4db74b0380f9ad53d3487bcc97f7)：军用车护航（车牌左侧带红点）。

# 其它特征

- [**乌克兰](https://www.notion.so/yangchenuci/GeoGuessr-2fae4db74b0380f9ad53d3487bcc97f7)：**红色街景车
- 斯里兰卡：车身模糊边缘一抹红、白、蓝相间的色块（视觉上非常像法国国旗）
- 智利：白车但露出一条黑边，光滑
- [**蒙古**](https://www.notion.so/yangchenuci/GeoGuessr-2fae4db74b0380f9ad53d3487bcc97f7)：车顶驮着巨大的帐篷或野营包。
- 阿根廷：有时黑车的左车头有黑杠头部和白色螺丝露出
