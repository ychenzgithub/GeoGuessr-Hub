# 水箱

# 美洲

- 墨西哥：特别常见，黑色水箱(有时白色)，Rotoplas
- 巴西：特别常见，蓝色水箱
- 玻利维亚：白色标签，上面写着“Tank-Burg”
- 哥伦比亚：黑色桶形水箱，或巴西式蓝色水箱
- 多米尼加：比墨西哥更宽的黑色桶状水箱
- 厄瓜多尔：蓝色水箱，比巴西更高些，上面写着“Piestigama”

# 中东

- 以色列：白色圆柱水桶（也是太阳能热水器）
- 巴勒斯坦：屋顶可能有大量黑色和白色水箱
- 约旦/阿联酋：白色水箱 （注意突尼斯没有水箱）

# 非洲

- 加纳/尼日利亚/乌干达/肯尼亚: 比美洲大的黑色水箱，通常放在建筑物的一侧或专门建造的塔楼
- 博茨瓦纳/斯威士兰/莱索托/南非: 绿色大水箱

# 亚洲

- 斯里兰卡：特别常见，黑色水箱
- 印尼：水箱比马来西亚更常见，有黄/橙色水箱

# 欧洲

- 希腊：金属水箱
- 土耳其：特别常见，太阳能热水器，通常带两个小水箱
- 意大利：西西里岛有各种浅色水箱
