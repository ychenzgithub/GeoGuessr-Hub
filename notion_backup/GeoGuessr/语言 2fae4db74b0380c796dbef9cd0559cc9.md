### 字符

- 北欧国家
    - 丹麦和挪威使用 Æ/æ 和 ø。
        - 丹麦：更常用b,d,g，常见-by, -skov, -rup，
        - 挪威：更常用p,t,k，常见-set, -heim, -stad，有时用到aa
    - 瑞典和芬兰（包括德国）使用 Ä/ä 和 Ö/ö。
        - 瑞典：还可以通过字母 å 来区分，有很多a。
        - 芬兰：有双元音(aa, ee, ii, yy)，双辅音（kk, tt, pp, ll, ss, mm, nn），极长单词
    - 冰岛和法罗群岛：使用 ð 。
        - 冰岛：还使用 þ 字符，经常用-ið
        - 法罗群岛：不使用 þ
- 波罗的海国家： 常拥有**极长的单词**
    - 爱沙尼亚：经常使用字母 õ。类似芬兰语，常有双元音。
    - 拉脱维亚：属于印欧语。在元音上方使用横杠（ā, ē, ī, ū），喜欢以-s, -a, -e 结尾。
    - 立陶宛：在字母e上方使用点（ė），并使用元音底下向右的鼻音钩（ą, ę, į, ų），一些辅音上常加倒折尖角符号č, š, ž，极其喜欢以 -as, -us, -is 结尾。
- 日耳曼语系
    - 德语: 有 `ß`
    - 荷兰语：很多双元音，比如ee, aa
- 中欧与东欧
    - 匈牙利：独特的双锐音符（ű ****和 ő），á等单锐音符经常出现，也喜欢用双辅音sz, zs, cs, gy, ny, ty 。例子：Magyarország, Szombathely
    - 捷克: 独特的抑扬符 ř ，常用圆圈 ů；注意抑扬符š, č, ž在其它国家（斯洛伐克，前南斯拉夫）也被使用。例子：Dvořák，Český
    - 斯洛伐克：抑扬符不使用ř ；跟捷克比有元音ô, ĺ, ŕ 以及 ä。例子：Liptovský，Námestovo
    - 波兰：斜杠 L（ł）；大量使用 z (sz, cz, rz, dz)和 w ；辅音多; 软音符 ś, ć, ź, ń; 尾巴字母 ą, ę。例子：Warszawa，Wrocław
    - 阿尔巴尼亚：多用q, j, k；包含特殊字符ç and ë。例子：Shqipëri， Rruga
- 南欧罗曼语族
    - 意大利：几乎所有单词都以元音（a, e, i, o）结尾，尤其是i；双辅音（tt, zz, pp, ss）多。例子：Roma，Milano，Piazza，Ristorante
    - 法语：常用ux;
    - 西班牙：“和”这个词是 `y`，“的”这个词是 de, 喜欢用用 `ñ`, ll 和反向标点（`¿, ¡`）。例子：España，calle，¿Dónde?
    - 加泰罗尼亚语：有中点l·l，ç 或 ny，少用`ñ`
    - 葡萄牙：“和”这个词是 `e`。“的”这个词是 do/da/de/dos/das。常用ão；使用 `ç`（也见于加泰罗尼亚语和法语，土耳其语）以及带波浪号的元音 `ã` 和 `õ`。例子：São，coração，informação
    - 罗马尼亚：大量使用向左的下加符（小逗号）ș 和 ț；元音常用半圆上标符â, ă 和 î。例子：București，Piața，România
    - 土耳其：关键字母有Ç ç，Ş ş，Ö ö，Ü ü，İ / ı（大写有点，小写没有）；一般没有 Q、W、X
- 法语，西班牙语，葡萄牙语比较
    - 王牌字母：法语`è` `à` `ù` `â` `ê` `î` `ô` `û` ; 西班牙语`ñ`； 葡萄牙语`ã` `õ` `lh` `nh`
    - And：法语`et`; 西班牙语`y`； 葡萄牙语`e`
    - Street：法语`Rue`; 西班牙语`Calle`； 葡萄牙语`Rua`
    - 常见后缀：法语`-tion` `-age` `-ette`; 西班牙语`-ción` `-dad`； 葡萄牙语`-ção` `-ções` `-dade`

- [西里尔字母](https://www.ptl.global/cyrillic-alphabet/)语言
    - 俄罗斯：独有Ё， Ы， Э， Ъ (Hard Sign)
    - 乌克兰：使用字母 i 和 ï （其它西里尔语言用И），Є， Ґ。例子：Україна，Київ
    - 保加利亚： 唯一使用西里尔字母的欧盟国家； 使用字母Ѝ， ъ （普通元音）；有单字母单词 **`в`**。例子：България，сън
    - 蒙古：使用字母 Ө
    - 吉尔吉斯：使用字母Ң，Һ
    - 巴尔干国家（塞尔维亚，波黑，黑山）同时使用拉丁(j)和西里尔脚本，通常带有 ђ 或 ћ, љ, њ字母。例子：Београд, Његош

- 东南亚语言
    - 泰国：圆圈+直线；比较规整；转折处带有一点点硬角；有很多垂直长线；有一个小圆圈作为起笔(有时候会用无头体，就没有这些圆圈)；
    - 老挝：基于泰语，弧线更多；圆圈更大；圆胖的字形；包含独特的字符（如 `ງ` 或 `ຽ`）。
    - 柬埔寨：顶部通常有类似波浪或尖刺的修饰，尤其是有很多向右的钩钩；笔画复杂且碎
    - 缅甸：几乎完全由圆圈和半圆组成加少量长竖线，弧线大部分闭合，像挤在一起的珍珠和泡泡。例子：`က`, `မ`, `တ`
    - 越南：拉丁字母；但每个单词都很短，且字母上下全是符号，甚至有双层符号

- 南亚语言
    - 印地语（天城文）：顶部的横线非常直，大多字母有垂直线字母形状相对“方正”和“稳重”；为印度北部主要语言
    - 古鲁木齐文：跟天成文类似，更圆润一些，有向下的夹子形字符；西北角旁遮普邦使用
    - 马拉地文：基于天成文，有ळ（一横下面挂个∞符号)和क्ष；主要在中西部的马哈拉斯特拉邦使用。
    - 古吉拉特文：跟天成文类似，没有顶部的横线；西边的古吉拉特邦使用
    - 孟加拉语：顶部的横线非常直，很多三角小旗形，尖角；孟加拉国以及印度东北部使用
    - Assamese：跟孟加拉语类似，但是三角小旗形字符常有多出一条线；在靠近孟加拉东北角的印度地区(Assam)使用
    - Manipuri：顶部有横线，下面很多竖线，有向下不封口的心形；孟加拉以东最东边Manipur地区
    - 英语：全印度都用，完全使用英语的是孟加拉以东的Meghalaya
    - Mizo: 完全由拉丁字母组成；在孟加拉以东的南部Mizoram地区
    - 奥里亚文：顶部经常有宽阔半圆形，类似骷髅头；印度中部偏东
    - Kannada 卡纳达语：很多弯曲，像电话线或蛇，右上角有像风间头发的波浪型；印度南方偏西区
    - Telugu 泰卢固语：很多弯曲，像电话线或蛇，上方有“对勾”或“小辫子”；例子：తె లు గు；印度南方偏东区
    - 马拉雅拉姆文：简单弯曲字母组成，有很多倒扣的u形和o形字母；印度西南角
    - 泰米尔文：有圆圈，曲线，直线，上部圆点变音符号；印度东南角和斯里兰卡使用
    - 斯里兰卡：僧伽罗（Sinhala）语，几乎全是圆弧线，完全没有顶部装饰，向上或侧面开口，像**一排排小屁股，桃子，爱心；例子：ඟ, ජ, ද**
    - 不丹：藏文，字母顶部有厚重的横笔，常能看到长长的“腿”
    - 巴基斯坦：从右往左写的类似阿拉伯文字

- 印尼 和 马来西亚：
    - 马来西亚：经常出现英语或双语
    - 印尼：单词拼写受荷兰语影响，英语里的 C 在印尼语常变成 K（Clinic → Klinik），tion 变成 si（Communication → Komunikasi）; 单词频繁以 `kan` 结尾，且使用字母 `a` 的频率极高；商店经常写成Toko。
- 日语、韩语与中文
    - 韩语因字符中频繁使用圆圈和椭圆而易于识别。
    - 日语结合了复杂的汉字（Kanji）和更简单、更圆润的拼音脚本（平假名/片假名）。
    - 中文字符看起来更紧凑、方正且笔画笔直。

### 路牌道路语言

- **停止标牌（Stop Signs）**
    - STOP — 国际通用（欧洲各国、英语国家、日本高速）
    - ALTO — 墨西哥及中美洲（危地马拉、洪都拉斯、萨尔瓦多、尼加拉瓜、哥斯达黎加、巴拿马）
    - PARE — 南美洲大多数国家（巴西、哥伦比亚、委内瑞拉、智利、阿根廷、秘鲁等）
    - ARRET — 加拿大魁北克省（法语区）
    - STOP + ARRET — 加拿大新不伦瑞克省（英法双语）
    - DUR — 土耳其
    - STOP + 阿拉伯文 — 突尼斯、摩洛哥
    - Waqif — 沙特阿拉伯等海湾国家（纯阿拉伯文）
    - Eist — 伊朗（波斯文）
    - 止まれ — 日本（平假名，三角形红色路牌）
    - STOP — 俄罗斯及部分前苏联国家（西里尔字母 СТОП）
- **道路词汇（按语言区）**
    - 斯堪的纳维亚 — Vag（瑞典）/ Vej（丹麦）/ Vei（挪威）/ Tie、Katu（芬兰）
    - 波罗的海 — Gatve / Kelias（立陶宛）/ Iela / Cels（拉脱维亚）/ Tee / Tanav（爱沙尼亚）
    - 德语区 — Strasse / Str.、Weg、Allee、Gasse
    - 法语区 — Rue、Avenue、Boulevard、Chemin
    - 西语区 — Calle、Avenida、Carretera
    - 加泰罗尼亚 — Carrer
    - 葡语区 — Rua、Avenida、Estrada（葡萄牙）/ Rodovia、BR-（巴西公路编号）
    - 俄语区 — ulitsa (ul.)、prospekt (pr.)、pereulok（小巷）
    - 意大利 — Via、Viale、Corso、Vicolo
    - 荷兰/比利时 — Straat、Weg、Laan
    - 科索沃 — 同时RR./UL.
    - 东南亚 — Jalan / Jl.（印尼/马来西亚）/ Thanon（泰国）
- **双语路牌**
    - 爱尔兰 — 英语 + 爱尔兰语（Gaeilge，绿底白字，通常斜体）
    - 芬兰 — 芬兰语 + 瑞典语（沿海瑞典语区）
    - 威尔士 — 威尔士语（上）+ 英语（下）
    - 希腊 — 希腊文（黄色）+ 拉丁转写英文（白色，国际公路上）
    - 法国布列塔尼 — 法语 + 布列塔尼语（Breton）
    - 保加利亚 — 西里尔字母 + 拉丁字母（无装饰符）
    - 黑山 — 西里尔字母 + 拉丁字母并用
    - 加拿大联邦公路 — 英语 + 法语
    - 南非 — 英语 + 南非荷兰语（Afrikaans）
    - 新加坡 — 英语为主，偶见中文/马来文/泰米尔文
- **警示与特殊路牌**
    - AWAS — 马来西亚（危险），常见于红底白字路牌
    - BAHAYA — 马来西亚 / 印度尼西亚（危险）
    - PERINGATAN — 印度尼西亚（警告）
    - Kura — 新西兰毛利语，意为学校，出现在学校路牌上
    - GEVAAR — 南非（南非荷兰语，危险）
    - ACHTUNG — 德国/奥地利/瑞士（注意/当心）
    - CUIDADO — 西班牙语国家（小心）
    - ATTENTION — 法语国家（注意）
