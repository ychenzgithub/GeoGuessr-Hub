# Africa

- [**Senegal](https://geohints.com/meta/flags) (塞内加尔) 🇸🇳：** **竖向**绿黄红 + 中心**绿星**。记忆：**“绿星闪耀”**。
- [**Nigeria](https://geohints.com/meta/flags) (尼日利亚)🇳🇬：** **竖向绿白绿**，无图案。记忆：**“纯净的农业与和平”**。
- [**Ghana](https://geohints.com/meta/flags) (加纳)🇬🇭：** **横向**红黄绿 + 中心**黑星**。记忆：**“黄金海岸黑星”**。
- [**Kenya](https://geohints.com/meta/flags) (肯尼亚)🇰🇪：** 黑红绿横条 + 中心**马赛盾矛**。记忆：**“战斗的防御”**。
- [**Uganda](https://geohints.com/meta/flags) (乌干达)🇺🇬：** **黑黄红**六道横条 + 中心**灰冠鹤**。记忆：**“会跳舞的起重机”**。
- [**Rwanda](https://geohints.com/meta/flags) (卢旺达)🇷🇼：** 宽蓝条 + 黄绿条 + 右上角**金太阳**。记忆：**“告别红色的和平”**。
- [**Namibia](https://geohints.com/meta/flags) (纳米比亚)🇳🇦：** **红斜条**（带白边）+ 左上角**金太阳**。记忆：**“沙漠阳光”**。
- [**Botswana](https://geohints.com/meta/flags) (博茨瓦纳)🇧🇼：** **浅蓝**底色 + **黑白**横条。记忆：**“水（Pula）与斑马”**。
- [**South Africa](https://geohints.com/meta/flags) (南非)🇿🇦：** 唯一的 **横向“Y”字型**，多色组合。记忆：**“和解的彩虹”**。
- [**Lesotho](https://geohints.com/meta/flags) (莱索托)🇱🇸：** 蓝白绿横条 + 中间黑色**巴索托帽**。记忆：**“高山民族风”**。
- [**Eswatini](https://geohints.com/meta/flags) (埃斯瓦蒂尼)🇸🇿：** 蓝黄红黄蓝 + 中心**黑白盾牌**。记忆：**“华丽的武士盾”**。

# Europe

## “十字”阵营（北欧与英伦）

- [**Denmark](https://geohints.com/meta/flags)🇩🇰**：红底 + 白色北欧十字。记忆点：**“北欧十字鼻祖，最简红白配”**。
- [**Sweden](https://geohints.com/meta/flags)🇸🇪**：蓝底 + 黄色北欧十字。记忆点：**“经典的宜家配色”**。
- [**Norway](https://geohints.com/meta/flags)🇳🇴**：红底 + 蓝十字（带白边）。记忆点：**“丹麦国旗上叠加了深蓝十字”**。
- [**Finland](https://geohints.com/meta/flags)🇫🇮**：白底 + 蓝色北欧十字。记忆点：**“白雪衬托着蓝色的湖泊”**。
- [**Iceland](https://geohints.com/meta/flags)🇮🇸**：蓝底 + 红色十字（带白边）。记忆点：**“冰川白、火山红、海洋蓝”**。
- [**Faroe Islands](https://geohints.com/meta/flags)🇫🇴**：白底 + 红十字（带蓝边）。记忆点：**“挪威颜色的反转版”**。
- Georgia:🇬🇪：白底+红十字，四边各有一小红十字
- [**Åland**](https://geohints.com/meta/flags)：蓝底 + 黄红双色十字。记忆点：**“瑞典国旗中心嵌入了红十字”**。
- [**United Kingdom](https://geohints.com/meta/flags)🇬🇧**：蓝底 + 红白叠加米字旗。记忆点：**“多国圣十字的米字重叠”**。
- [**Greece](https://geohints.com/meta/flags)🇬🇷**：蓝白条纹 + 左上角蓝底白十字。记忆点：**“爱琴海的蓝白条纹”**。
- [**Switzerland](https://geohints.com/meta/flags)🇨🇭**：红色正方形 + 中心白色等臂十字。记忆点：**“唯一的正方形，红十字会反色”**。
- [**Malta](https://geohints.com/meta/flags)🇲🇹**：左白右红竖条 + 左上角灰色马耳他十字。记忆点：**“白红双色配银灰色勋章”**。

## “垂直三色”阵营（西欧与南欧）

- [**France](https://geohints.com/meta/flags)🇫🇷 (法国)：** **蓝-白-红**。现代三色旗的老祖宗。
- [**Belgium](https://geohints.com/meta/flags)🇧🇪 (比利时)：** **黑-黄-红**。颜色源自其纹章。
- [**Italy](https://geohints.com/meta/flags)🇮🇹 (意大利)：** **绿-白-红**。把法国的蓝换成绿（罗勒叶、意面）。
- [**Ireland](https://geohints.com/meta/flags)🇮🇪 (爱尔兰)：** **绿-白-橙**。注意最右边是橙色（代表新教徒）。
- [**Romania](https://geohints.com/meta/flags)🇷🇴 (罗马尼亚)：** **蓝-黄-红**。和非洲的乍得几乎一模一样。
- [**Andorra](https://geohints.com/meta/flags)🇦🇩 (安道尔)：** **蓝-黄-红** + 中心有国徽。

## “水平三色”阵营（中欧、东欧与波罗的海）

- **经典红白蓝系列：**
    - [**Netherlands](https://geohints.com/meta/flags)🇳🇱 (荷兰)：** **红-白-蓝**。横向三色旗的始祖。
    - [**Luxembourg](https://geohints.com/meta/flags)🇱🇺 (卢森堡)：** **红-白-浅蓝**。比荷兰的蓝更浅。
    - [**Russia](https://geohints.com/meta/flags)🇷🇺 (俄罗斯)：** **白-蓝-红**。泛斯拉夫颜色的来源。
- **泛斯拉夫/东欧变体：**
    - [**Germany](https://geohints.com/meta/flags)🇩🇪 (德国)：** **黑-红-金**。
    - [**Austria](https://geohints.com/meta/flags)🇦🇹 (奥地利)：** **红-白-红**。传说英雄血染白袍。
    - [**Hungary](https://geohints.com/meta/flags)🇭🇺 (匈牙利)：** **红-白-绿**。
    - [**Bulgaria](https://geohints.com/meta/flags)🇧🇬 (保加利亚)：** **白-绿-红**。
    - [**Estonia](https://geohints.com/meta/flags)🇪🇪 (爱沙尼亚)：** **蓝-黑-白**。极其独特的冷系色彩。
    - [**Latvia](https://geohints.com/meta/flags)🇱🇻 (拉脱维亚)：** **暗红-白-暗红**。白色条纹非常窄。
    - [**Lithuania](https://geohints.com/meta/flags)🇱🇹 (立陶宛)：** **黄-绿-红**。在欧洲很少见的配色，很像非洲。

- [**New Zealand**](https://geohints.com/meta/flags) (新西兰) 🇳🇿：**蓝底** + 左上**英国国旗** + 右侧**四颗红心白边星**。记忆：**“四颗红星”** (与澳洲区分的关键)。
- [**American Samoa**](https://geohints.com/meta/flags) (美属萨摩亚) 🇦🇸：**右侧白三角**内有**白头海雕**。记忆：**“带老鹰的白三角”**。
- [**Guam**](https://geohints.com/meta/flags) (关岛) 🇬🇺：**蓝底红边** + 中心**梭形徽章**。记忆：**“红边蓝旗”**。
- [**Northern Mariana Islands**](https://geohints.com/meta/flags) (北马里亚纳群岛) 🇲🇵：**蓝底** + 中心**石柱**与**花环**。记忆：**“蓝底石柱花环”**。
- [**Vanuatu**](https://geohints.com/meta/flags) (瓦努阿图) 🇻🇺：**红绿黑**底色 + 黄色**Y型条纹** + **猪牙**图案。记忆：**“黄色Y型与猪牙”**。
- [**Christmas Island**](https://geohints.com/meta/flags) (圣诞岛) 🇨🇽：**蓝绿斜分** + 中心**黄圆**内有**金鹲**。记忆：**“蓝绿地，金鸟飞”**。
- [**Cocos (Keeling) Islands**](https://geohints.com/meta/flags) (科科斯群岛) 🇨🇨：**绿底** + 左上**棕榈树** + 中心**黄星月**。记忆：**“绿底棕榈树”**。
- [**Pitcairn Islands**](https://geohints.com/meta/flags) (皮特凯恩群岛) 🇵🇳：**蓝底** + 左上**英国国旗** + 右侧**绿色纹章**。记忆：**“蓝底英国旗加绿盾”**。
